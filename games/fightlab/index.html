FIGHTLAB

BUILD. COMBINE. FIGHT.

Game Overview

FightLab ist ein schneller Multiplayer-Arena-Shooter rund um eigene Loadouts, chaotische Kämpfe und unvorhersehbare Fähigkeitskombinationen.

Vor jedem Match stellen die Spieler ihr eigenes Setup aus Waffen, Schadensarten, Effekten, Rüstung, Gadgets und Ultimates zusammen. Sobald die Runde beginnt, reagieren diese Bausteine dynamisch miteinander und erzeugen schnelle, physikbasierte Kämpfe, in denen Kreativität und Timing wichtiger sind als reines Aim.

Jede Runde spielt sich anders — abhängig davon, welche Kombinationen die Spieler bauen und wie sie ihre Loadouts während des Kampfes einsetzen.

Worum geht es?

  • Baue vor jedem Match deinen eigenen Kampfstil
  • Kombiniere Waffen mit besonderen Schadensarten und Statuseffekten
  • Nutze Gadgets und einmalige Ultimates während des Kampfes
  • Rüste Perks für passive Fähigkeiten aus
  • Tritt in schnellen Arena-Matches mit ständig wachsendem Chaos an

Loadout System

Das Loadout ist das Herz von FightLab. Statt einer festen Klasse kombinierst du vor jeder Runde einzelne Bausteine zu einem eigenen Build. Starke Kombinationen können viel Schaden verursachen, Gegner kontrollieren oder deine Beweglichkeit verbessern — doch jedes Loadout hat klare Schwächen.

Weapons

Waffen bestimmen die Grundfunktion deines Angriffs. Das aktuelle Platzhalter-Arsenal umfasst schnelle Projektile, schwere Einzelschüsse, Flächenwaffen und physikbasierte Werkzeuge.

Damage Types

Schadensarten verändern, wie eine Waffe auf Spieler, Rüstung und die Arena reagiert. Sie können für direkten Schaden, Flächenkontrolle oder besondere Synergien ausgelegt werden.

Effect Types

Effekte geben Treffern zusätzliche Eigenschaften. Verlangsamung, Rückstoß, Schaden über Zeit und andere Statusveränderungen lassen sich mit passenden Waffen und Schadensarten kombinieren.

Armor

Rüstung beeinflusst Schutz, Gewicht und Beweglichkeit. Mehr Widerstand bedeutet nicht automatisch das bessere Setup — besonders dann nicht, wenn Mobilität für deine Kombination wichtig ist.

Gadgets

Gadgets sind aktive Werkzeuge für einzelne Kampfsituationen. Sie schaffen Raum, verändern Positionen oder geben dir im richtigen Moment einen taktischen Vorteil.

Ultimates

Ultimates sind mächtige Fähigkeiten, die nur einmal pro Match eingesetzt werden können. Das richtige Timing kann eine verlorene Runde drehen.

Perks

Perks gewähren passive Fähigkeiten und vervollständigen deinen Build. Sie verstärken bestimmte Spielstile, ohne eine feste Klasse vorzuschreiben.

Cosmetics

Cosmetics verändern das Aussehen deines Kämpfers und deiner Ausrüstung. Sie haben keinen Einfluss auf Werte oder Gameplay.

Navigation & Match Flow

Main Menu

Vom Hauptmenü aus wechselst du zum Loadout-Editor, startest oder suchst eine Lobby und passt deine Einstellungen an.

Hosting

Spieler können eigene Matches hosten und grundlegende Regeln wie Arena, Rundenzahl und Teilnehmerzahl festlegen.

Lobby

In der Lobby treffen sich die Spieler vor dem Match, prüfen ihre Bereitschaft und nehmen letzte Änderungen am Loadout vor.

Levels

Die Arenen sind auf schnelle Bewegung, Sichtlinien und physikbasierte Interaktionen ausgelegt. Unterschiedliche Level fördern unterschiedliche Loadout-Kombinationen.

Anforderungen

Windows Minimum

  • Betriebssystem: Windows 10, 64-Bit
  • Prozessor: Intel Core i5-8400 / AMD Ryzen 5 2600
  • Arbeitsspeicher: 8 GB RAM
  • Grafik: NVIDIA GTX 1060 / AMD RX 580
  • DirectX: Version 11
  • Speicherplatz: 8 GB verfügbar
  • Sound: DirectX-kompatible Soundkarte

Windows Empfohlen

  • Betriebssystem: Windows 11, 64-Bit
  • Prozessor: Intel Core i7-9700 / AMD Ryzen 5 5600
  • Arbeitsspeicher: 16 GB RAM
  • Grafik: NVIDIA RTX 2060 / AMD RX 6600
  • DirectX: Version 12
  • Speicherplatz: 8 GB auf SSD
  • Sound: DirectX-kompatible Soundkarte

macOS Minimum

  • Betriebssystem: macOS 12 Monterey oder neuer
  • Prozessor: Intel Core i5 / Apple M1
  • Arbeitsspeicher: 8 GB RAM
  • Grafik: Intel Iris Plus / Apple M1
  • Speicherplatz: 8 GB verfügbar
  • Hinweis: Ältere Intel-Grafikchips werden nicht unterstützt

macOS Empfohlen

  • Betriebssystem: macOS 14 Sonoma oder neuer
  • Prozessor: Apple M2 / Intel Core i7 mit 2,6 GHz
  • Arbeitsspeicher: 16 GB RAM
  • Grafik: Apple M2 GPU / Radeon Pro 5500M
  • Speicherplatz: 8 GB auf SSD
  • Hinweis: Controller empfohlen

Hinweis: Systemanforderungen, Preis, Plattformen und technische Detailangaben sind Platzhalter für den Prototyp.
